# Sikkerhet

## Melde fra om en sårbarhet

Har du funnet en sårbarhet på status.norskitdrift.no eller i dette repoet, ta kontakt via kanalene i
[security.txt](https://status.norskitdrift.no/.well-known/security.txt) (filen ligger i
`src/.well-known/security.txt`).

- Beskriv hva du fant, hvor (URL eller fil) og hvordan det kan gjenskapes.
- Ikke opprett et offentlig GitHub-issue for sårbarheter.
- Ikke test på måter som kan skade tjenesten eller andres tilgjengelighet.

## Omfang

- Statussiden status.norskitdrift.no (statiske filer på Cloudflare Pages, ingen Functions)
- GitHub Actions-workflowene i `.github/workflows/`
